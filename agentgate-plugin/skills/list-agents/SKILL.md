# AgentGate: List Agents

Call the MCP tool `agentgate_agents_list` to retrieve all registered agents with their status, capabilities, and connection info.

Usage:
- Run this skill to see who's online in the mesh
- Works with both local and remote agents

The tool returns agent id, name, description, capabilities, and current status (idle/busy/error/offline).
